# MVP モック (現行実装ステージ)

neco 指示 (2026-08-09): まず入力遅延と実現可能性を判断するための MVP モックを作る。
フルセット設計 (spec/plan/design.md) のうち、以下だけを実装する。

## 実装範囲

- サーバ + 常駐 C# ヘルパ (csc.exe 自動ビルド) + SendInput 注入 (text/key/mouse)。
- ペアリング PIN + トークン (LAN にキー注入面を無認可で開かないため MVP でも省かない)。
- 単一ページ UI。**画面左端の切替バーを「素早く 2 回押す」とペインが循環切替**
  (iOS/Android のキーボード切替の operating model)。ペイン:
  1. **キーボード** — テキスト送信 (確定送信 + ライブ送信) + JIS 特殊キーバー
  2. **タッチパッド** — 相対移動 / タップ=クリック / 2 本指スクロール / ボタン
  3. **ショートカット (静的モック)** — 固定ボタン数個 (プロファイル機構は未実装)
- **遅延 HUD**: 各メッセージに seq を付け、server ack (ヘルパ注入完了後) までの RTT を
  ms 表示 (直近値 + 移動平均)。遅延判断が MVP の目的のため必須。
